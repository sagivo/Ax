# Ax — Language & Toolchain Specification v0.3

This file is the in-repo copy of the v0.3 spec the implementation is
tracking. It supersedes `spec/card.md` (research-v1 / v0.2) wherever they
disagree. The card remains the short agent-facing divergence list.

Implementation language: **Rust**. Backends: **Cranelift** (dev) + **C11/LLVM
via cc -O3** (release; the existing C backend is the LLVM-class path until
an in-process LLVM crate lands). Extension `.ax`.

## 1. Five ideas

1. **One tree.** The agent-canonical surface is a prefix list. There is
   no operator precedence, no infix, no accept-and-elide. Each construct
   has one spelling; the printer is the inverse of the parser. The
   Rust-shaped conventional surface is a *legacy corpus dialect* so the
   four backends keep proving the same IR. It is not the language.
   Implementation language remains **Rust** — that is the compiler, not
   the surface. See `DECISIONS.md` (R-14).
2. **Never-rejecting ownership inference.** Strategy ladder: register →
   stack → unique heap → region → RC → atomic RC. Failure to prove a
   cheaper strategy degrades and emits a *performance* diagnostic.
3. **Prove, else check, always report.** Surviving checks appear in
   `ax perf --json`. Checkable contracts (`#[no_alloc]`, `#[no_rc]`,
   `#[no_panic]`, `#[no_bounds_checks]`, `#[stack_only]`, `#[max_alloc(n)]`,
   `#[pure]`, `#[total]`, `#[inline(always)]`) refuse to compile on
   violation.
4. **Constrained generation.** `ax complete --at` returns type-correct
   completions and a GBNF fragment of the *tree* grammar. Target:
   syntax_err_rate = 0, hallucinated symbol rate = 0. A list grammar
   makes this a real constraint, not a reconstruction of Rust.
5. **Trust and sensitivity.** `Untrusted[T]` and `Secret[T]` are lattice
   annotations (same layout as `T`). IO produces `Untrusted`. Sinks reject
   it. `Secret` cannot be logged, formatted, serialized, or sent over FFI.
   `own T` is affine.

## 2. Kill criteria

See `DECISIONS.md`. Week-12 tooling-on-Rust measurement is mandatory.
C-parity is abandoned if residual RC > 8% or median > 1.4× C after the
perf loop.

## 3. Surface (defined as a tree, not by subtraction from Rust)

The language is the prefix tree in `crates/ax/src/tree.rs`. A file that
opens with `(` is that surface. There is no Rust to subtract from.

The conventional parser still accepts a Rust-shaped dialect so the
existing corpus, `ax k1`, and `ax silent-wrongness` keep running. That
dialect is not extended. New programs are trees.

Assignment: move when the source is not used again; copy on conflict and
emit `P1010`. Affine `own` use-after-move is error `A2020`.
