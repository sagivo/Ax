A compiler that answers in microseconds.

Ax is a compiled systems language whose primary consumer is a program, not a person. You write #add(a,b)=a+b. The checker returns in 176 µs. Hole fills are known to compile. Fixes that change meaning are refused.

Attempts-to-green is the loop

ax check --json is in-process. ax hole --fills synthesises candidates, substitutes each one, and only returns fills that type-check. A protocol over rustc still pays 361–612 ms. Process launch is the floor there; --emit=metadata alone is 37 ms.

20% fewer tokens vs best mainstream

Dense on purpose

Nine common methods, exact o200k_base BPE: Ax 107, Python 133, TypeScript 185, Rust 226, C 237. One spelling per construct. A formatter that strips BPE-costing whitespace. Shortening fn to f would not help — both are already one token.

silent wrongness 36% vs Rust 64%

The language says no

Effects live in the signature. Pure functions may be cached; io never is. own T is affine. Untrusted[T] cannot reach sinks. Secret[T] cannot be logged. Three backends must agree. Tier-divergent: Ax 0%, Rust 18%. A protocol over Rust cannot copy this table.

Fast where a guarantee does the work

Same algorithm, identical output. The harness refuses a time unless every backend printed the same value. Fastest of 21 runs.

Where the work is a plain loop, Ax lands on clang and clang’s result is what you get. Go wins primes by ~15% with the same instruction class — scheduling, not work. “Faster than any other language on identical machine-level work” is not a claim this table supports except where a language guarantee does the work, or on the agent loop itself.

Hot path

One kqueue / epoll reactor. Keep-alive and pipelining. Connection buffers reused. Literal bodies serialized once and proven static by lowering. fn(http.Request) -> http.Response compiled to native code. No reflection, no middleware, no per-request allocation on the static path.

API framework in the language

Handlers are ordinary typed functions. ax-api is a standalone source generator — the compiler has no router. 

// ax-api port 8080
// ax-api GET /health -> health
// ax-api GET /v1/items/{id} -> show
// ax-api POST /v1/items -> create

fn health(request: http.Request) -> http.Response =
    api.ok({ok: true});

fn show(request: http.Request, id: String) -> http.Response =
    api.ok(id);

fn create(request: http.Request) -> http.Response =
    api.created(request.body);

What you get

Verb routes, path / query / header / cookie extraction, typed JSON bodies, api.ok / created / no_content, generated /openapi.json and /docs, optional SQLite or MySQL pool, TLS, watch mode.

Expand, then compile. Inspect with ax-api expand. Framework routing measured 145,382 req/s against 145,044 for hand-written Ax — 0.23%, noise. 

ax-api new my-api
ax-api run my-api/app.ax
