Ax card (v0.3 / research-v1)

This is Ax. #name, :=, c??t:e, i~n, +/n, type glyphs. Default parse and ax fmt. A file that opens with ( is the prefix tree. Rust-shaped fn / module / let still parses so the corpus keeps proving the IR. An agent does not write it.

own T is affine. Untrusted[T] / Secret[T] cannot reach sinks / logs. ax perf --json is the second diagnostic loop.

Compiled systems language for LLM agents. Extension .ax. Text is authoritative. Primary consumer: a program. Humans are second.

Axioms

  • Minimize attempts-to-green.
  • One spelling per construct.
  • Interfaces expose all language-level observable behavior.
  • Pure core is deterministic; effectful runs are transcript-replayable.
  • Every trust boundary is explicit.

#sum(n:Z)=+/n
#sumv(xs V[Z])Z=+/xs#

#name(a T)R=body is a function. Omitted signature types are I. a,b:T shares T. name T:=e binds. i~n loops 0..n. c??t:e is if/else. @c{body} is while. ^e returns. e?d option-or. e|d result-or.

Type atoms: I i32 · L i64 · Y isz · U u32 · W u64 · Z usz · B bool · F f64 · f f32 · S string · O option · R result · M map · V vec.

A file that opens with ( is the tree: (fn add ((a i32) (b i32)) i32 (+ a b)).

Effects, errors, memory, trust

Effects inferred in the body, checked against the declaration. Empty row = effect-free, including termination. raise / catch / attempt become a result. At most one err[E]. Regions are lexical bump arenas. Exclusive mut. No reborrow. own T use-once. IO produces Untrusted; sinks reject it. Secret cannot be logged, formatted, serialized, or sent over FFI. par is rejected in v1.

ax hole --fills returns only candidates that compile after substitution. ax fix --apply applies only semantics_preserving edits. Full loop: protocol.md.

HTTP

fn handle(request: http.Request) -> http.Response =
    if request.path == "/health" {
        http.response(200u16, "{\"ok\":true}")
    } else {
        http.response(404u16, "{\"error\":\"not_found\"}")
    };

fn main() -> unit !{io[net], abort} = http.serve_handler(8080u16, handle);

Build: ax build --tier release app.ax.
